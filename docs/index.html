@chirag127/design-system

Framework-agnostic design tokens, themes, atomic web components, a11y primitives, and keyless AI clients — one pnpm monorepo, a distinct look per site.

The @chirag127/* monorepo powering ~80 oriz sites. Shared mechanism, never a shared look: a --oz-* token contract, themes, framework-agnostic atoms, accessibility primitives, and keyless AI clients. Reuse the mechanism, override the tokens — every site earns its own identity.
